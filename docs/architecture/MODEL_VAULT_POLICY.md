# Model Vault Policy

## Rolle

Der Model Vault speichert Metadaten, Lizenzen, Notices, Inventare, Checksums und
spaeter freigegebene Modellartefakte in IDrive e2.

## Repo-Regeln

- keine Modellgewichte
- keine grossen Binärdateien
- keine Medienarchive
- keine Secrets
- nur kleine Beispiel-Manifeste

## Inferenz

Der Vault ist kein Inferenzsystem. Inferenz braucht BYOK, Partner-Compute oder
Self-host und muss separat freigegeben werden.
