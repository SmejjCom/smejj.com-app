# Frontend Changelog

## 2026-07-07

- Linke Navigation auf klare Icon+Label-Eintraege umgestellt.
- Unklare Labels ersetzt: `smejj claw` -> `Coding`, `Chat History` -> `Verlauf`, `Konto` -> `Nutzer`.
- Unklare Icons ersetzt: Neu nutzt Plus, Coding nutzt Code, Automatisierung nutzt Blitz/Zahnrad.
- Navigation-Schutztest ergaenzt, damit falsche Icons, fehlende Labels oder entfernte Menuepunkte den Build blockieren.
- Linke Navigation danach auf die sieben Kernpunkte reduziert: Neu, Suche, Coding, Projekte, Dateien, Verlauf, Einstellungen. Kosten/Nutzer liegen unter Einstellungen, Automatisierung unter Coding, Websites/Browser rechts.
- Suche Codex-artig umgesetzt: globale Suche ueber Chats, Projekte, Dateien, Code, Quellen und Verlauf; Treffergruppen waehrend der Eingabe, Enter oeffnet den besten Treffer, Cmd/Ctrl+K fokussiert Suche.
- Keine DB-Migration noetig.
