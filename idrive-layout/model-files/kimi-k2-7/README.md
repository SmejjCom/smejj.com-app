# Kimi K2.7 Vault

Kimi K2.7 is stored as a model-vault target only.

It is not a free default engine, not a browser-free full model, not a GitHub
asset and not a Cloudflare Workers AI dependency.

Allowed future inference modes:

- BYOK
- partner-compute-later
- self-host-later

Default inference mode: `disabled`.

Real model weights must not be committed to this repo. Store real artifacts in
IDrive e2 only after source, storage, transfer machine, license and checksums
are explicitly approved.
