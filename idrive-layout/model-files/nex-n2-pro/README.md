# Nex N2 Pro Model Vault

This folder is only a small layout placeholder. Real Nex N2 Pro model files,
GGUF quantizations, tokenizer files, configs, checksums and notices belong in
IDrive e2, not in GitHub.

Contabo may cache only a small verified GGUF quantization temporarily for a
single job or short TTL. If the selected quantization does not fit the 8 GB RAM
server profile, inference must stay disabled and the job status must be written
back to IDrive e2.
